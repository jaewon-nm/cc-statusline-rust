New `config color <kind> [--fg <c>] [--bg <c>] [--bold | --no-bold] [--clear]` subcommand. 18 new tests (10 e2e in `tests/preview_and_color.rs`, 5 unit in `render::color::tests`, 3 in `config::tests`); 123 / 123 total.
