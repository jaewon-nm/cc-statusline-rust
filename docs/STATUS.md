## Implementation history

- **2026-05-14 — 006 default theme color completed.** Default theme now emits ANSI escapes; underlying text invariant unchanged. Each widget produces a `Vec<Segment>` with its own theme styles (model cyan-bold, cwd blue, session_tokens magenta, session_cost yellow, git_branch green, git_status yellow, git_changes +green/-red, bar widgets multi-segment with bracket/empty default and filled cells tier-colored). Renderer applies user `cfg.colors[kind]` as a whole-widget override that **replaces** every segment style end-to-end. Threshold helper `bar_tier_color(pct)` at 50% / 80% boundaries → green / yellow / red. New `ColorMode::{Auto,Always,Never}` library seam so snapshot tests pin `Always` and plain-invariant tests pin `Never` without mutating env (`renderer_default_invocation_matches_golden_plain` keeps the public `NO_COLOR=1` opt-out path covered end-to-end). Codex round 1 DISAGREE on `default_layout().colors` baking, env-mutation test pattern, and CLI flag scope; round 2 DISAGREE on widget vs renderer override mechanics; round 3 AGREE; round 4 small precedence + defensive `to_style()` nits. 18 new tests (`bar_tier_color` boundaries, `ColorMode` Always/Never, per-widget theme color assertions, plain-text invariant under `Never`, ANSI-by-default integration). 166 / 166 total; clippy + fmt clean. Golden snapshot at `tests/snapshots/render_default_theme__default_theme_snapshot.snap` rolled forward.
- **2026-05-14 — 005 install/uninstall completed.** New top-level subcommands `ccstatusline-rs install` / `uninstall`. Install resolves `--bin-dir` (default `~/bin` on Windows, `~/.local/bin` on POSIX), copies the running binary, writes a `.mjs` Node wrapper on Windows (Claude Code Windows-native `statusLine` regression workaround), backs up `~/.claude/settings.json` to `<file>.ccstatusline-rs-bak-<ts>-<NNN>`, then rewrites only the `statusLine` block through a typed `ClaudeSettings { statusLine, #[serde(flatten)] extra }` struct so every unrelated key survives byte-equivalent. Uninstall finds the latest backup by fixed-width-lex sort and restores via `crate::ioutil::atomic_write_bytes` (temp + rename); `--purge-binary` also removes our exe + wrapper. Codex 4-round verify-plan AGREE (preserve_order rejected, typed `FileIo` / `NoBackupFound` variants, counter-suffixed backups, POSIX single-quote escaping, pure helpers cross-platform-tested). 25 new tests (14 unit in `ioutil` + `install::tests`, 11 integration in `tests/install_uninstall.rs`); 148 / 148 total. See [`exec-plans/completed/005-install-uninstall.md`](exec-plans/completed/005-install-uninstall.md).
